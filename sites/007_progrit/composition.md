## LAYOUT-008 / 超大型見出しヒーロー

一言: 画面を占める特大の和文見出しを2段、間に太い下線、周囲に斜めの角丸装飾シェイプを散らし、右下に角丸の大きな切り抜き画像を置くヒーロー。

- 見出しが主役。特大サイズで2行、間に太い横線(下線)を挟む。下に小さなラベル(MISSION等)。
- ナビは右上に控えめ。CTAはピル型アウトライン。
- 装飾: 角丸の傾いた長方形シェイプ(濃淡オレンジ)を斜めに複数散りばめて動きを出す。
- 右下に角丸を大きく取った切り抜き画像。
- 適する用途: スタートアップ/採用色の強い、勢いとメッセージ性重視のトップ。

## LAYOUT-009 / 価値観カードグリッド(3+2中央寄せ)

一言: 中央見出しの下に、アイコン+英語見出し+本文のカードを上段3列・下段2列で、どちらも中央寄せに配置するグリッド。

- カードは白地・薄い影・角丸。中身は「丸アイコン → 英語見出し → 本文」を中央寄せ。
- 5枚を 3 + 2 に分け、下段2枚も中央に寄せる(左詰めにしない)。
- 適する用途: バリュー/行動指針など、奇数個の項目を均整よく見せたいとき。

## DECO-012 / 浮き立体カードのサービス紹介

一言: 角丸のカラーシェイプを立体的に浮かせ(影+わずかな3D回転)、隣にテキストを置く左右2カラムのサービス紹介。

- 片側に角丸の塗りカードを大きく置き、強めのドロップシャドウ+`perspective`での軽い回転で浮遊感。
- 反対側にサービス名+サブ見出し+本文+ピル型CTA。
- 適する用途: 主力サービスを印象的に1つずつ見せるブロック。

## DECO-013 / 人物はみ出しメッセージカード

一言: 横長の白カードにメッセージを置き、人物写真をカード右端から外にはみ出させて重ねる。

- 白い角丸カード(影付き)を画面幅の8〜9割で配置。
- 中に「英語ラベル(CEO MESSAGE)→ 見出し2行 → ピル型CTA」。
- 人物写真をカードの右端〜外側にはみ出させ、立体感と視線誘導を作る。
- 適する用途: 代表メッセージ、人物を主役にした紹介。

## LAYOUT-010 / ダーク中央CONTACT + 大型フッター

一言: 暗い写真背景に大型英字「CONTACT」を中央寄せ、その下にダーク背景の多カラム大型フッター(ロゴ+4カラムのリンク群+コピーライト行)。

- CONTACT: 暗背景に中央寄せで大見出し+補足+白いピル型CTA。
- フッター: 左にロゴ、右に4カラム前後のリンク群(見出し+リンク列)。下にコピーライト+補助リンクの横一列。
- 適する用途: ページ末尾。問い合わせ誘導とサイトマップを兼ねる締め。

## 再現のキモ

1. ヒーロー見出しは font-size を非常に大きく。下線は太い矩形を見出し間に挟む。装飾シェイプは角丸矩形を `rotate` で傾けて絶対配置。
2. カードグリッドは flex/grid を中央寄せ(`justify-content:center`)。3+2でも中央に揃える。
3. 浮き立体は `box-shadow` を大きく+`perspective() rotateY()` 微調整。
4. 人物はみ出しはカードを `position:relative`、人物を `position:absolute` で右下に置き枠外へ。
5. フッターは CSS Grid で `200px repeat(4,1fr)` のような多カラム。

※ 配色は対象外(形のみ)。オレンジは構造把握用の仮色。
