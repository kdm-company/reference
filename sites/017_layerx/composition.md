# 017 LayerX / グローバルナビ+メインビジュアル(形のみ)

- **URL**: https://layerx.co.jp/
- **対象**: グローバルメニュー、メインビジュアル
- **骨格HTML**: skeleton.html
- **形タグ**: `#余白極大` `#特大タイポ` `#ミニマルヘッダー` `#複合ピルCTA` `#スクロール演出` `#スタートアップ`

## LAYOUT-018 / 余白極大タイポヒーロー

一言: 画面の大半を余白にして、下1/3に特大の黒コピー2行だけを置くタイポグラフィ主導のヒーロー。

- 写真もイラストも使わない。白背景+特大コピー(ビューポート高の8%前後のフォントサイズ)を左下寄せ。
- 背景に細いラインのSVGグラフィック(円・斜線など)を薄く敷き、スクロールに連動してゆっくり動かす。
- 右下に「scroll+丸ボタン」のダウン指標、右上に丸いスクロール進捗インジケータがfixedで追従。
- コピーはスクロールで切り替わる(ミッション→メッセージ)演出も実物にはある。
- 適する用途: ミッションを一言で強く見せたいスタートアップ・テック企業のトップ。コピーの強度が要求される。

## DECO-025 / 複合ピルCTA

一言: 影付きの白いピル形の器の中に「塗りピル+枠ピル」を2つ並べた2重構造のCTAボタン。

- 外側: border-radius最大+box-shadowの白い器(padding 5px前後)。
- 内側: 主導線は塗りピル(実物: 青紫「Join Us」)、副導線は枠/淡色ピル(「採用情報」)。ラベルを英字+和文で分けるのも一手。
- ヘッダー右端に置き、スクロールしても目立つ。1つのCTAに2つの入口(例: 採用トップ/募集一覧)を持たせられる。
- 適する用途: 採用強化中の企業ヘッダー。主+副の2導線を1ボタンに見せたいとき。

## 再現のキモ

1. ヒーローの余白が本体。コピー以外の要素(ヘッダー・指標類)は全て小さく細く。
2. 特大コピーは clamp() でフォントサイズをビューポート連動にする(例: clamp(40px, 7vw, 96px))。
3. ライングラフィックは stroke細めのSVGをabsoluteで散らし、IntersectionObserver+transformでゆっくり動かす。
4. ナビは通常リンクの薄いテキスト。ドロップダウン(私たちについて/採用情報)は小さな三角のみで存在を示す。
5. スマホはnavを隠してmenuボタン→全画面オーバーレイに。

※ 配色は対象外(形のみ)。実物は白ベース+濃紺文字+青紫アクセント。
