# 003 岩崎電気 / コンテンツ要素 + 固定ヘッダー(形のみ)

- **URL**: https://www.iwasaki.co.jp/
- **対象**: ①濃色背景のテキスト+画像コンテンツセクション ②スクロール時に出る固定ヘッダー
- **骨格HTML**: skeleton.html
- **形タグ**: `#英語ラベル付き見出し` `#下線見出し` `#テキスト左画像右` `#交互積み` `#固定ヘッダー` `#ハンバーガー併設`

## DECO-003 / セクション見出しの型

一言: 小さな英語ラベルを上に置き、その下に和文大見出し、見出しの左下に短い下線、右下に細い斜め線(tick)を添える見出しの型。

- 英語ラベル(小・大文字)→ 和文見出し(太・大)の2段。
- 見出し下に左寄せの短い下線(全幅でなく一部だけ)。
- 見出し右下から細い斜め線が伸びる装飾(岩崎電気特有のあしらい)。
- 「会社情報 ─ Corporate」のように見出し横に水平線+英語を並べる派生もあり。

## LAYOUT-003 / テキスト左・画像右セクション(交互)

一言: 濃色背景に、左にテキストブロック(DECO-003の小見出し型)、右に横長画像を2カラムで組み、縦に積むレイアウト。

- 2カラム(テキスト / 画像)。左テキスト・右画像が基本。
- 同じ型を縦に繰り返してコンテンツ一覧にする。
- 反転(画像左・テキスト右)も型として用意(.rev)。
- 背景は濃色(原典は濃紺)。文字は白で抜く前提。
- 適する用途: 企業サイトの「採用」「企業情報」などの誘導セクション群。

## DECO-004 / スクロール時の固定ヘッダー

一言: スクロールすると上から出てくる白背景の横長固定ヘッダー。左にロゴ+言語トグル、右にテキストメニュー+ハンバーガー+検索アイコン。

- 白背景・横幅いっぱい・下に細い境界線。
- 左: ロゴ + 丸みのある言語トグル(JA/EN)。
- 右: テキストメニュー横並び + ハンバーガー(≡) + 検索(⌕)。
- テキストメニューとハンバーガーを **併設** するのが特徴(メニューの二重提供)。
- 適する用途: 項目数が多いサイトで、主要導線をヘッダーに出しつつ全項目はハンバーガーに退避。

## DECO-005 / 放射状グロー背景(左上から差す光)

一言: 濃紺背景の左上寄りから、ぼんやり明るい光が差すCSS装飾。**写真ではなくコード(radial-gradient)。**

- 判定根拠: 中心から外周へ均一に減衰する楕円のにじみで、写真特有のノイズ・色ムラがない。HTMLにも該当画像要素がなく、背景はCSSで描画。
- 作り方: 濃紺ベースの上に `radial-gradient(ellipse at center, 明るい青 → 中間 → 透明)` を `::before` で重ねる。位置は左上寄り(top:-10% / left:18% など)。
- ポイント: 光は要素の外にはみ出させ(top:マイナス)、`overflow:hidden` で柔らかく切る。中身は `z-index` で光の上に乗せる。
- 適する用途: 濃色背景セクションに奥行き・先進感を出したいとき。テック・光関連と相性良。

## 再現のキモ

1. 見出しは英語ラベル(小)+和文(大)の縦積み。下線は `::after` で左寄せ短め。斜めtickは細線をrotate。
2. コンテンツ行は CSS Grid 2カラム。`.rev` で order を入れ替えて交互配置。
3. 固定ヘッダーは `position:fixed; top:0` + スクロール量で表示切替(原典はスクロールダウンで出現)。
4. ヘッダー右はテキストメニュー + アイコン2つ(ハンバーガー・検索)を flex で横並び。

※ 配色は対象外(形のみ)。背景の濃紺は骨格では淡色で代用。
