# 012 日本ゼトック / トップページ全体テンプレ(形のみ)

- **URL**: https://www.zettoc.co.jp/
- **対象**: トップページ全体(ヘッダーからフッターまで丸ごと)
- **骨格HTML**: skeleton.html
- **形タグ**: `#トップ全体` `#コーポレート` `#インセット動画MV` `#ニュースバー` `#右上角丸` `#オーバーラップカード`

## LAYOUT-013 / コーポレートトップ全体構成

一言: 「言語バー付きヘッダー → インセット動画MV → 強み → 会社概要 → 事業 → 特集 → ニュース2列 → CONTACT → フッター」の王道コーポレート一直線構成。

セクションの並び(そのままテンプレとして使える):

1. **ヘッダー**: 最上部に言語切替の細いユーティリティバー、その下にロゴ左+nav右。
2. **MV**: 画面幅いっぱいにせず左右に余白を残した「インセット動画」(aspect 1360:700、暗幕オーバーレイ+中央ロゴ)。左下に濃色半透明のニュースバー(News | 日付+タイトル | Moreピル)を重ねる。
3. **強み(PROUD)**: 英字大見出し+リード(左)×縦長画像(右)の2カラム → 直後の背景帯に3カード(DECO-019)が上へはみ出して重なる。
4. **会社概要**: 中央寄せの細い定義リスト。全幅の罫線の「頭160pxだけ」アクセント色にするあしらい。関連会社ロゴは4列グリッド。
5. **事業内容**: サムネ左+事業名の横型ミニカード4連+ボタン。
6. **特集(SPECIAL)**: 大カード2枚+横長1枚(DECO-020)。
7. **ニュース2列**: CSR活動×お知らせを左右対称に。各列「見出し+Moreボタン → 日付リスト」。
8. **CONTACT**: 中央寄せで英字見出し+和文+リード+TEL大+ボタン。
9. **フッター**: ロゴ+navカラム+下段ユーティリティリンク。

- 全体のモチーフ: 画像・ボタン・カードの角を「右上だけ」丸める(border-top-right-radius)。実物はティール(#009baa)+濃紺(#002846)。
- 適する用途: メーカー・BtoBコーポレートのトップ。セクション順をそのまま流用できる。

## DECO-019 / 番号バッジ付き画像カード3連(帯に上はみ出し)

一言: 画像の左下に正方形の番号バッジ(01〜03)を載せたカード3枚を、背景帯へ negative margin で重ねる。

- カードは「画像(右上角丸) → 見出し → 説明 → More(右寄せ矢印)」。番号はCSSカウンタで自動連番も可。
- カード列を transform:translateY(-110px) 等で持ち上げ、背景帯(色ベタ or 写真)に半分乗せる。
- 適する用途: 強み・事業の柱など「3つの○○」訴求。

## DECO-020 / 大画像+はみ出し白ボックスの特集カード

一言: 大きな画像の右上に番号、左下に白い情報ボックスを下へはみ出させた特集バナー。

- 画像は aspect 580:400(横長版は1160:300)。右上に番号スクエア、左下の白ボックスは bottom をマイナスにして浮かせる。
- 白ボックスは「タイトル+サブ」+下辺にアクセント色のborder-bottom。カード全体に薄いshadow。
- 2枚横並び+全幅1枚の組みで変化をつける。
- 適する用途: 特設コンテンツ・LP誘導など、大きく見せたい導線が2〜3個あるとき。

## 再現のキモ

1. 右上だけの角丸(border-top-right-radius)を画像・ボタン・カードで統一すると全体の統一感が出る。
2. MVはインセット(margin-inline)+ニュースバー重ねで「全画面MV」との差別化。
3. はみ出し系(DECO-019/020)は「negative margin / マイナスbottom」+重なり先のpadding確保のセット。
4. スマホ: ニュースバーはMV下へstatic落とし、3カードは1列、特集カードは全て1列、ニュース2列は縦積み。

※ 配色は対象外(形のみ)。
