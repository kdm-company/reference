# 010 セブン-イレブン / サービス案内グリッド + 取組み紹介(形のみ)

- **URL**: https://www.sej.co.jp/
- **対象**: サービス案内のリンク群、取組み紹介のカード群
- **骨格HTML**: skeleton.html
- **形タグ**: `#リンクグリッド` `#サービス案内` `#取組み紹介` `#カード横並び` `#見出し+説明`

## LAYOUT-011 / サービス案内リンクグリッド

一言: 「見出し+短い説明」の小ブロックを複数、均等なグリッドで並べたサービス・導線一覧。

- 3列前後のグリッド(項目数に応じて2〜4列)。各ブロックは枠線か薄い区切りで仕切る。
- 各ブロックは「リンク見出し → 1〜2行の説明」。
- 画像を使わず、テキストリンク中心で多数の導線をコンパクトに並べる型。
- 適する用途: 大規模サイトのトップで、サービス・企業情報・採用など多数の入口を一覧化したいとき。

## DECO-016 / 取組み紹介カード横並び

一言: サムネ画像+見出し+説明のカードを3〜4列で横並びにした、取組み・特集の紹介ブロック。

- 中央のセクション見出しの下に、カードを等幅グリッドで横並び。
- 各カードは「画像 → 見出し → 説明文」の縦積み。
- LAYOUT-011(テキストのみ)より視覚的。画像で内容を示す。
- 適する用途: CSR・特集・キャンペーンなど、画像付きで複数トピックを並べる紹介。

## 再現のキモ

1. どちらも CSS Grid。リンクグリッドは `repeat(3,1fr)`、取組みカードは `repeat(4,1fr)` 目安。
2. リンクグリッドは画像なし・テキスト中心で密度高く。取組みはサムネ付きで余白広め。
3. スマホでは列数を落とす(1列 / 2列)。

※ 配色は対象外(形のみ)。
