# 011 幕張ベイパーク耳鼻咽喉科 / ヘッダー+全画面KV+診療メニュー(形のみ)

- **URL**: https://makuhari-jibika.yukenkai.com/
- **対象**: ヘッダー(メガメニュー)、メインビジュアル、診療内容セクション
- **骨格HTML**: skeleton.html
- **形タグ**: `#メガメニュー` `#全画面KV` `#オーバーラップカード` `#受付時間表` `#正方形パネル` `#クリニック`

## DECO-017 / 画像カード付きフルワイドメガメニュー

一言: 固定ヘッダーのnavにhoverすると、画面幅いっぱいのドロップダウンが開き、中にサムネ付きリンクカードが並ぶ。

- ヘッダーは fixed・白背景。左にロゴ+医院名、右に横並びnav(hoverで下線が伸びる)。
- ドロップダウンは position:absolute; top:100%; width:100% で全幅。淡色背景+下方向のbox-shadow。
- 中身は左に「一覧を見る」リンク、右にサムネ+ラベルの小カードを5列グリッド。カードはhoverでtilt(3D傾き)。
- 適する用途: 診療案内・製品カテゴリなど、下層が多く画像で選ばせたいナビ。

## LAYOUT-012 / 全画面KV+右下オーバーラップ情報カード

一言: 全画面写真スライドの中央に1文字ずつ現れるキャッチ、右下に受付時間+TELの白カードが次セクションへはみ出す。

- KVは高さ calc(100vh - ヘッダー高)。背景は写真スライドショー(vegas等でクロスフェード)。
- 中央に「小バッジ(開院日) → キャッチ2行 → サブコピー1文」。キャッチはspan分割の文字送りアニメ。
- 右下の白カードは position:absolute; bottom をマイナスにして次セクションに重ねる。中身は曜日×時間帯の受付時間表+TEL。
- 左下に小さなお知らせボックス。次セクション側はカードのはみ出し分だけ padding-top を確保。
- 適する用途: クリニック・店舗など「営業時間と電話」を最初に見せたいサイトのトップ。

## DECO-018 / 正方形リンクパネル横並び(診療メニュー5連)

一言: 1:1の正方形リンクパネルを5枚横一列に並べた診療・サービスメニュー。枠の上下に細いラインのあしらい。

- パネルは width:calc(100%/5) + padding-top:calc(100%/5) (または aspect-ratio:1/1)で正方形を保証。
- 各パネルは「アイコン → 名称 → 補足(小)」の中央寄せ縦積み。枠線内側の上下に短い水平ラインを飾る。
- hoverでtilt(3D傾き)。セクション見出し(英字小+和文大)+リード文+枠線ボタンを上部に添える。
- 適する用途: 診療科目・サービス分類など、5±2個の入口を均等に見せたいとき。

## 再現のキモ

1. メガメニューは「header直下のabsolute全幅」+ opacity/pointer-events 切替。カード側grid は repeat(5,1fr)。
2. KVの情報カードは bottom:-60px 前後のマイナス配置と、次セクションの padding-top 確保をセットで。
3. 正方形パネルは aspect-ratio が最短。古い書き方なら padding-top トリック。
4. スマホ: メガメニューはアコーディオンへ、情報カードは static に戻して全幅、パネルは2列。

※ 配色は対象外(形のみ)。実物は白+ベージュ(#FAF8F5系)+茶系アクセント。
