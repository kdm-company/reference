## LAYOUT-014 / 製造業トップ全体構成

一言: 「全画面クロスフェードMV → 強みの同期スライダ → 製品 → 採用 → ニュース → CVフッター」のBtoB製造業テンプレ。

セクションの並び(そのままテンプレとして使える):

1. **ヘッダー**: ロゴ左+言語リスト(jp/kr/en)+ハンバーガー。navは全画面ドロワーで、末尾にCONTACTボタン。
2. **MV**: 高さ100vh。背景写真3枚がケンバーンズ(ゆっくり拡大)しながらクロスフェード。コピーは中央でなく「右寄り・上下中央」に英字小+和文大2行+サブ。左下に縦線が伸びるscroll指標。
3. **強み(三つの軸)**: テキスト×画像の同期スライダ(DECO-021)。
4. **製品紹介**: 左端に背景帯(写真)を敷き、製品画像を下げて帯に半掛かりにするずらし2カラム。右にテキスト(英字見出し+大コピー+箇条書き+ボタン)。下に全幅の製品群イメージ。
5. **採用**: 写真背景の帯。画像左+白文字コピー右+白ボタン。
6. **ニュース**: 3カード(画像上+日付+タイトル)。PCは縦型カード3列、スマホは「画像左44%+テキスト右」の横型カード1列に切り替わる。
7. **CVフッター**: 濃色帯にリード文+白い箱(TEL大+受付時間+ボタン)を中央配置。フッター本体はロゴ+横並びnav+コピーライト。

- 見出しは全セクション共通で「英字(Oswald・大文字)大+和文小」の2段。実物のアクセントは紺(#003C87)。
- 適する用途: BtoB製造業・技術系企業のトップ。CVフッター(電話+問い合わせ)まで含めた一直線構成。

## DECO-021 / 番号ページャ付き テキスト×画像 同期スライダ

一言: 左のテキスト(番号ページャ01/03+見出し+説明+next)と右の画像が同期して切り替わるスライダ。

- 2カラム: テキスト側41%、画像側55%。テキスト上部に「01 / 03」の現在番号ページャ。
- 各スライドは「番号 → 見出し(コピー) → 説明文 → next矢印」。nextクリックとオートプレイで両側が同時に送られる。
- slick等の`asNavFor`(スライダ連結)で実装するのが定石。
- 適する用途: 「3つの強み」「事業の柱」など、少数の訴求を1つずつじっくり見せたいとき。

## 再現のキモ

1. MVのケンバーンズは背景3枚を absolute 重ね+`scale`アニメ(13.5s infinite)を時間差(0s/4.5s/9s)で回す。
2. MVコピーの「右寄せ・上下中央」(top:52%; right:9%)が中央置きとの差別化ポイント。
3. 製品セクションのずらしは「::beforeで左に帯 → 画像にmargin-top → テキストはpadding-top小さめ」の3点セット。
4. ニュースカードのPC縦型/スマホ横型切替は、カード内部をgridにして列定義だけ差し替える。

※ 配色は対象外(形のみ)。
