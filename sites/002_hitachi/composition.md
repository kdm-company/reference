# 002 日立 / トップビュー + カードパーツ(形のみ)

- **URL**: https://www.hitachi.com/ja-jp/
- **対象**: ①トップのファーストビュー ②採用情報・株主情報で使われるコンテンツパーツ
- **骨格HTML**: skeleton.html
- **形タグ**: `#中央寄せヒーロー` `#フルブリードスライダー` `#2段ヘッダー` `#ピル型CTA` `#カード重ねオフセット`

## LAYOUT-002 / トップビュー

一言: 画面いっぱいの背景に、コピーを中央寄せで置くフルブリードヒーロー。左右に矢印がつくスライダー。

- **ヘッダーは2段**: 上段=右寄せのユーティリティ(言語切替/問い合わせ/検索)。下段=ロゴ左+メニュー横並び(ドロップダウン付き)。
- **ヒーロー**: フルブリード。コピーは上下左右とも中央寄せ。
- **CTA**: 角を完全に丸めたピル型ボタン(白地)。中央コピーの下。
- **スライダー**: 左右端に `‹ ›` の矢印。複数スライドを切り替える前提。
- 適する用途: 大企業・グローバル系トップ、力強い印象。

## DECO-002 / カード重ねオフセットパーツ

一言: 大きな横長画像の角に、テキストカードを少し重ねて配置するパーツ。左右反転で交互に並べる。

- 横長画像を片側に大きく置き、反対側の下角にテキストカードを **オーバーラップ** させる。
- カードは白地・薄い影・枠線あり。中に見出し+本文+ピル型CTA。
- **奇数番=画像右/カード左下、偶数番=画像左/カード右下** と交互に反転させてリズムを作る。
- 適する用途: トップページの誘導ブロック(採用・IR等)を縦に並べるとき。

## 再現のキモ

1. ヒーローは flex で縦横中央寄せ。背景はフルブリード、コンテンツだけ中央。
2. CTAは `border-radius` を高さ以上にしてピル型。
3. カードパーツは画像とカードを `position:absolute` で重ね、`box-shadow` で浮かせる。重なり量は画像幅の1〜2割。
4. 交互反転は type-A / type-B のクラスで左右を入れ替えるだけ。

※ 配色は対象外(形のみ)。

## スマホ版の構造(SP / 〜768px)

- **ヘッダー**: 2段のうち下段メニュー横並びをハンバーガー(≡)化。上段ユーティリティは詰める。
- **ヒーロー**: 高さ圧縮。左右スライダー矢印は隠し、スワイプ操作前提。
- **DECO-002 カード重ねオフセット**: 角での重ねをやめ「画像 → カード」を縦積み。カードはわずかに上へ重ねて(`margin-top:-30px`)立体感だけ残す。左右反転(type-A/B)はSPでは無効。
- 実装は skeleton.html の `@media(max-width:768px)` を参照。
