# 005 Apple系 / 製品ヒーロー・カード・タブ・グリッド(形のみ)

- **URL**: apple.com/jp、apple.com/jp/mac、support.apple.com/ja-jp
- **対象**: ①製品ヒーロー ②2カラム関連情報カード ③ピル型セグメントタブ ④角丸カード非対称グリッド
- **骨格HTML**: skeleton.html
- **形タグ**: `#中央寄せヒーロー` `#ピル型CTA` `#角丸カード` `#セグメントタブ` `#非対称グリッド` `#薄グレー背景`

## LAYOUT-005 / 中央寄せ製品ヒーロー

一言: 薄グレー背景に、製品名(大)+サブコピー+ピル型CTA2連を上部中央に置き、その下に製品画像を中央配置するヒーロー。

- 全要素 中央寄せ。縦に「見出し → サブ → CTA2つ → 製品画像」。
- CTAはピル型を2つ。主=塗りつぶし、副=線(アウトライン)で並べる。
- Apple定番の製品紹介ブロック。複数縦に並べてラインナップを見せる。

## DECO-008 / 2カラム関連情報カード

一言: 中央のセクション見出しの下に、角丸ビジュアル+見出し+本文+リンクのカードを2カラムで並べる。

- 2カラム等幅。各カードは「角丸ビジュアル(アイコンや写真)→ 見出し → 本文 → テキストリンク」。
- ビジュアルは `border-radius` 大きめの角丸。
- 適する用途: 関連情報・サポート導線などの並列紹介。

## DECO-009 / ピル型セグメントタブ

一言: 大見出しの下に、グレーのトラックに乗ったピル型のセグメントタブ。選択中だけ黒く塗りつぶした丸。

- グレー地のピル型トラックの中に、複数のタブを横並び。
- 選択中タブだけ濃色(黒)で塗りつぶし、文字は白。他はグレー文字。
- 適する用途: 製品カテゴリ等のフィルター切替。

## LAYOUT-006 / 角丸カードの非対称グリッド

一言: 大きな角丸の白カードを、上段=全幅1枚、下段=2カラム(大小)に組む非対称グリッド。

- 上段に全幅の幅広カード(中央寄せの文章)。
- 下段は2カラムだが幅が非対称(例 2:1)。左=情報量多い大カード、右=小さい注意カード。
- カードは白地・大きな角丸・たっぷりの内側余白。
- 適する用途: サポート/お知らせ等、重要度の異なる情報を整理して見せる。

## 再現のキモ

1. ヒーローは `text-align:center` で縦積み。CTAは `border-radius` を高さ以上にしてピル型、塗り/線で主副を分ける。
2. カードのビジュアルは角丸 `border-radius:16〜20px`。
3. セグメントタブはグレーのトラック(pill)に子のタブを入れ、選択中に `.on` で黒塗り。
4. 非対称グリッドは CSS Grid。`grid-column:1 / -1` で全幅カード、下段を `2fr 1fr` 等で非対称に。

※ 配色は対象外(形のみ)。CTAの青やカード色は構造把握用の仮色。
