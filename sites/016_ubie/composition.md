# 016 Ubie / グローバルナビ+メインビジュアル+サービス(形のみ)

- **URL**: https://ubie.life/
- **対象**: グローバルメニュー、メインビジュアル、サービス紹介セクション
- **骨格HTML**: skeleton.html
- **形タグ**: `#淡グラデヒーロー` `#対象者別導線` `#正方アイコンCTA` `#サービス交互ブロック` `#タグピル` `#ヘルスケア`

## DECO-023 / アイコン付き正方ダブルCTA(ヘッダー右端)

一言: ヘッダー右端に「アイコン上+ラベル下」の正方形CTAを色違いで2個、ヘッダー高いっぱいに並べる。

- 各CTAは縦積み(アイコン20px+ラベル10px前後)で幅80px程度の正方形ブロック。角丸なし・隙間なしで右端にぴったり。
- 導線の性質で色を分ける(実物: 青=お問合せ / ピンク=採用情報)。
- golfcartの横長ダブルCTA(LAYOUT-015)のバリエーション。より省スペースでアイコンが主役。
- 適する用途: 問い合わせ+採用のように性質の違う2導線を常時見せたいヘッダー。

## LAYOUT-017 / 淡グラデヒーロー+対象者別リンク3連バー

一言: 白〜淡色の斜めグラデ背景に黒の大コピーを左寄せし、その下に「〇〇の方はこちら」の枠線ボタンを3本横並びにする。

- 背景は写真なし。淡いピンク〜白の斜めグラデ+ぼかしシェイプ。コピーは黒の大見出し2行+サブ2行、左寄せ。
- コピーの下に対象者別リンク(アイコン+ラベル+矢印)を等幅3連。枠線のみの控えめなボタンで、ファーストビューから3種の来訪者を振り分ける。
- 適する用途: 複数の対象者(顧客/パートナー/求職者など)が来るコーポレートトップ。

## DECO-024 / 対象者タグピル付きサービス交互ブロック

一言: 「対象者タグピル → 製品ロゴ(見出し扱い) → 説明 → ストアバッジやピルボタン」のテキスト構成で、画像と左右交互に組むサービス紹介。

- 2カラム(画像44%目安)を奇数/偶数で反転させて3ブロック縦積み。ブロック間は余白広め(90px目安)。
- テキスト側の順序がキモ: 小さな枠線タグピル(生活者向け等)で対象を宣言 → 製品ロゴ画像をそのまま見出しに → 説明文 → アクション(アプリはストアバッジ2個+WEB版ピル、BtoBは「サービスを見る→」ピル1個)。
- セクション見出しは英字1語(Services)をアクセント色で小さく。
- 適する用途: 対象者ごとに製品が分かれるマルチプロダクト企業のサービス一覧。

## 再現のキモ

1. ヒーローのグラデは linear-gradient の角度115度前後+中間で色を切り替えると「斜めの面」が出る。
2. 対象者リンクは grid repeat(3,1fr)。スマホは1列縦積み。
3. 交互ブロックは .blk と .blk.rev(flex-direction:row-reverse)の2クラスで管理。
4. 製品ロゴを見出しにする場合、h2相当の位置にimg(高さ30px前後)を置き、altに製品名。

※ 配色は対象外(形のみ)。実物は白ベース+ピンク/青アクセント。
