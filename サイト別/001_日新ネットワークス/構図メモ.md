# 001 日新ネットワークス / トップビュー(形のみ)

- **URL**: https://www.nisshin-networks.co.jp/
- **対象**: トップのファーストビュー(ヘッダー + ヒーロー)
- **骨格HTML**: 骨格.html(ブラウザで開くと構造が見える)
- **形タグ**: `#フルブリードヒーロー` `#左テキスト右ビジュアル` `#横並びナビ` `#斜め曲線リボン`

## 一言でいうと

左にコピー、背景に俯瞰3Dビジュアルを敷き、斜めの曲線リボンが奥行き方向に走るフルブリードヒーロー。ヘッダーはロゴ左・CTA右上・その下に横並びナビ。

## 形の骨格(LAYOUT-001)

- **ヘッダー**: 上段=左ロゴ / 右にCTAボタン2つ。下段=グローバルナビ横並び、項目を斜線スラッシュ `/` で区切り、下に細い境界線1本。
- **ヒーロー**: 画面幅いっぱい(フルブリード)。高さ大きめ(600px前後)。
- **コピー配置**: 左8%・縦30%あたりに寄せる。和文大見出し2段 + 欧文サブの3要素を縦積み。
- **背景ビジュアル**: 俯瞰視点のビジュアルを背面フルに敷く。前面のコピーと重ねる(オーバーレイ構造)。
- **リボン**: 右下から左上へ斜めに走る帯。clip-pathで斜めの形を作る。ヒーローの象徴。

## 再現のキモ

1. ヒーローは `position:relative` の箱に、背景ビジュアル・リボン・コピーを `position:absolute` で重ねる三層構造。
2. ナビの区切りは罫線でなく文字の `/`。
3. 大見出しは字間を広げる(letter-spacing大)とこのサイトらしい落ち着きが出る。
4. 全体に余白を多くとる。窮屈にしない。

※ 配色は対象外(形のみ保管)。
