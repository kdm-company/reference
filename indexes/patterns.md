# 柄集(背景パターン横断 / 図柄そのもの)

背景に敷く柄の一覧。使いたいIDを Claude Code に渡す。
柄は色そのものが成果物なので例外的に図柄を保存(主要色 #334155 を淡く・控えめ密度)。濃さは opacity で調整。

## PATTERN-001 / ドット(規則正しい水玉)

- 規則正しい水玉を等間隔に敷いた下地。タイル 24x24・円半径2.4。
- 主要色 #334155(濃さは fill-opacity)。淡く控えめでどんな背景にも重ねやすい。
- 用途: 余白の単調さを抑えたい広い背景、セクションの下地。
- 原本: patterns/PATTERN-001.svg

## PATTERN-002 / ストライプ(斜めの細い線)

- 45度の細い斜線を等間隔に敷いた下地。線幅2・間隔14。
- 傾きは patternTransform の rotate 値で変更可。主要色 #334155(濃さは fill-opacity)。
- 用途: 端正で動きを出したい帯・CTA・見出し背景。
- 原本: patterns/PATTERN-002.svg

## PATTERN-003 / グリッド(細い格子)

- 縦横の細線でつくる方眼の下地。マス 24x24・線幅1。
- 主要色 #334155(濃さは stroke-opacity)。設計図的で工業・技術系の印象。
- 用途: 専門性を出したい技術紹介・資料的セクションの下地。
- 原本: patterns/PATTERN-003.svg

## PATTERN-004 / 市松(チェッカー)

- 淡い市松(チェッカー)の下地。マス20・タイル 40x40。
- 主要色 #334155(濃さは fill-opacity)。やわらかな陰影でリズムを出す。
- 用途: 軽い装飾感を足したい背景、写真の無い面の単調さ回避。
- 原本: patterns/PATTERN-004.svg
